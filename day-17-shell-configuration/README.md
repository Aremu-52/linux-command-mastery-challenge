## What I practiced
I added a permanent environment variable and a custom alias to my `.bashrc`, reloaded it with `source`, and confirmed the changes. I also practiced viewing system-wide configuration files and using `type`, `which`, and `whereis`.

## What surprised me
I was surprised that Ubuntu does not have a `.bash_profile` by default (it uses `.bashrc` and `.profile` instead). Also, `source ~/.bashrc` is a very convenient way to apply changes without opening a new terminal.
