## Commands covered today
See [commands.md](./commands.md) for all 10 commands with syntax and my own explanation of what each one does and when I would reach for it.

## What I practiced
I identified my machine’s IP address and default gateway, tested connectivity with ping, fetched a URL and its headers with curl, downloaded a file with wget, and listed all listening ports using both netstat and ss.

## What surprised me
I was surprised how much clearer `ss -tulnp` is compared to the older `netstat`, and how easy it is to get a full picture of the network configuration with just a few commands.
