# Day 11: Creating & Managing Users

**Phase 3 – Users, Groups & Package Management | Day 11 of 30**

## Commands covered today
See [commands.md](./commands.md) for all 10 commands with syntax and my own explanation of what each one does and when I would reach for it.

## What I practiced
I created a new user with a home directory and Bash shell, set a password, added the user to a secondary group, changed the shell, renamed the account, and finally deleted the user together with the home directory.

## What surprised me
I was surprised how many options `useradd` and `usermod` have. Creating a user properly (with home directory and correct shell) is very important in real systems.
