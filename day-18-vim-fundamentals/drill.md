# Day 18 Practice Drill

## Task
Open a new file in vim, type three lines of text, save it, reopen it, delete the middle line, undo the deletion, then save and quit.

## Commands / Actions I practiced

```bash
vim day18.txt


Pressed i to enter Insert mode and typed three lines
Pressed Esc to return to Command mode
Used :w to save
Used :wq to save and quit
Used :q! to quit without saving
Used dd to delete a line
Used yy and p to copy and paste a line
Used :q to quit
Used u to undo and Ctrl + r to redo

Result

Successfully practiced all basic Vim operations: opening, inserting, saving, quitting, deleting, copying, pasting, undoing and redoing.

What I learned
Vim has two main modes (Insert and Command). Once you remember to press Esc before running commands, editing becomes much faster.
