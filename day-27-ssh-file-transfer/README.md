## What I practiced
I generated an SSH key pair, copied the public key, connected with and without a password, used different SSH options (`-p`, `-i`), and transferred files using `scp`, `sftp`, and `rsync`. I also looked at the SSH client config and server config.

## What surprised me
I was surprised that after using `ssh-copy-id`, I could log in to localhost without typing a password. Also, `rsync` is very efficient compared to normal copy.
