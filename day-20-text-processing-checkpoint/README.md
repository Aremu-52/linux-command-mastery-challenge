## What I practiced
I practiced filtering text with grep, sorting, removing duplicates with uniq, extracting columns with cut and awk, replacing text with sed, and combining them into a single pipeline.

## What surprised me
I was surprised how powerful a single pipe chain can be. With one command line I was able to filter errors, extract timestamps, sort them, and remove duplicates.
