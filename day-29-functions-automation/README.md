## What I practiced
I turned a script into a reusable function that accepts a service name as an argument, checks whether the service is running, restarts it if needed, logs the action, and scheduled the script to run hourly with cron.

## What surprised me
I was surprised how powerful functions and positional arguments are. With one script I can now check and restart any service just by passing its name.
