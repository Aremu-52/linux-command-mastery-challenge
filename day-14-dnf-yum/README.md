## What I practiced
I practiced package management commands from different systems (DNF, YUM, RPM, Snap, APT repository, dpkg, pip, and npm). Even though some commands are for RHEL-based systems, I successfully used Snap, dpkg, pip, and npm on Ubuntu.

## What surprised me
I was surprised that modern Ubuntu blocks system-wide pip installs by default for safety, and that Snap provides an easy way to install applications across different Linux distributions.
